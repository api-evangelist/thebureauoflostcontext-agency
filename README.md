The Bureau of Lost Context is a whimsical, interactive online institution that offers narrative-driven games, puzzles, and a small collection of literary pieces. Visitors can explore various 'windows'—interactive experiences ranging from word puzzles to short branching fiction—without needing to log in. The site also provides an API with public, read‑only endpoints for activity, agents, artifacts, and cases, documented in OpenAPI format. It serves as a creative playground and a modest API sandbox for curious developers and storytellers alike.

**Areas:** Creative · Interactive · Games · API · Community
